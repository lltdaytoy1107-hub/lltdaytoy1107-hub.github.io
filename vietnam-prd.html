VIETNAM VERSION / PRODUCT REQUIREMENTS DOCUMENT · V0.2

越南版本
MVP PRD

基于既有中文 App 的产品骨架，围绕越南语长文本、本地特色活动、机构审核与账号入口完成低成本、可运营的市场适配。

产品策略：复用国内版本文档状态：业务基础版适用范围：发布 · 审核 · 交易

01 / 项目判断

PRODUCT DECISION

先复用骨架，再补齐越南市场边界

不重做完整用户旅程，优先明确服务类型、发布主体、审核责任和交易状态。

NON-GOAL

不在 MVP 阶段扩张复杂能力

暂不新增复杂等级体系、推荐算法或 AI 功能，也不把未验证的上线效果写成事实。

02 / MVP 目标

01 / SUPPLY

机构发布

合作旅行机构可以发布旅行团、特色体验和地陪服务。

02 / REVIEW

机构审核

本地人可提交地陪服务，但不能绕过合作机构审核直接上线。

03 / TRANSACTION

用户交易

越南用户可以浏览服务，完成登录、咨询、下单和支付。

04 / CONTROL

平台可控

区分角色、发布状态、审核状态和交易状态，保证运营边界清晰。

03 / 用户与权限

角色主要目标核心权限
越南用户 / 旅行者浏览并购买适合自己的旅行服务浏览、筛选、详情、登录、咨询、下单、支付、订单、评价
国内本地人提供面向越南旅客的地陪服务创建草稿、提交审核、查看结果、按要求修改
合作旅行机构提供服务、审核供给、管理订单发布三类服务、审核地陪服务、接单、处理履约
平台运营 / 管理员维护版本、权限与运营秩序管理机构、配置服务类型、查看审核、处理争议

04 / 核心业务规则

SERVICE TYPES

三类服务供给

旅行团与特色体验由合作旅行机构发布；地陪服务可由本地人提交，但必须经过机构审核。

STATUS FLOW

审核状态可追踪

草稿 → 待审核 → 审核中 → 需修改 / 已驳回 / 已通过 → 已发布 → 已下架

规则边界：只有“已通过”内容可以进入“已发布”。审核驳回或要求修改时必须提供原因；关键字段变化时，建议触发重新审核。

05 / 核心流程

01 / PUBLISH

机构发布服务

选择服务类型，填写内容、图片、价格、时间、地点和注意事项，保存草稿或提交发布。

02 / REVIEW

本地人提交审核

填写服务、语言能力和资质材料，提交合作机构审核，并根据结果修改。

03 / DISCOVER

越南用户浏览

按服务类型浏览，查看详情与发布方，登录后咨询或下单。

04 / AFTERCARE

交易与售后

支付后查看订单与通知，完成服务后评价；支付失败、取消或超时时提供明确反馈。

06 / 交付边界与职责

MY CONTRIBUTION

把团队规则转化为可执行的产品方案

基于团队与业务负责人确定的市场边界，我参与梳理服务类型、角色权限、本地化约束和验收规则，并将其转化为 PRD 与前台信息架构、页面呈现。

ENGINEERING DELIVERY

后台能力由研发通过接口和权限实现

发布、审核、权限、订单状态与支付回调主要由研发实现；后台页面不纳入本作品集展示范围，不将研发页面产出表述为我的视觉设计。

证据方式：本案例保留团队已确定的业务边界，同时明确我的参与重点是规则梳理、产品转化、前台适配与验收协作；后台能力以产品规则、权限矩阵、状态流转和研发验收说明。

07 / 越南语本地化约束

LANGUAGE QA

AI 初稿必须人工复核

AI 生成越南语初稿后，由越南语人员复核，再完成业务事实核对后发布。

LAYOUT CAPACITY

按两倍文本容量设计

越南语变长时优先增加容器高度、自然换行或拆分信息层级，不通过缩小字号解决溢出。

TRANSACTION SAFETY

交易信息不得被截断

价格、时间、地点、取消规则和关键交易信息不得被省略号隐藏；缺少翻译或审核未完成的内容默认不可发布。

FORMAT QA

先校验文本长度与页面溢出

本阶段优先检查长标题、长地址、按钮、标签、弹窗和固定操作区，不扩展为完整后台页面验收。

08 / 验收标准

通过条件：三类服务的发布主体和接单主体符合规则；未经机构审核的地陪服务不会出现在前台；用户可以区分三类服务；登录、支付成功/失败/取消/超时和订单状态均有明确反馈；核心页面完成越南语复核与中文基线两倍文本压力测试；桌面端与 390px 无横向溢出、按钮截断、弹窗遮挡或关键交易信息缺失。后台发布、审核、权限与支付接口以规则和研发验收为准，不作为本案例页面设计成果展示。

09 / 待确认事项

登录与支付平台、机构准入和认证方式、本地人资质、审核时限、库存与退款规则、翻译责任人、语言回退策略，以及图片内文字是否同步制作越南语版本，仍需业务与运营方确认。
